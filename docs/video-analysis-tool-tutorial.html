What changed in version 2

A separate Frame editor, exact-frame groups with yellow staging, numbered/color-coded merge destinations, member Move/Remove controls, Saga map categories, and recoverable cleanup directly from the gallery and groups.

Similarity scanning now supports up to 1,000 individual retained Keep frames. Keep all / clear proposed discards reports what it cleared; it is not a bulk Keep action.

Start the dashboard

/opt/local/bin/python3 tools/soda-frame-review/server.py \
  --port 8767 --archive "/path/to/timestamped-recording"

Open http://127.0.0.1:8767/. Use an existing Python environment with Pillow and NumPy; the illustrated commands use the project's configured environment.

Private by default. Do not commit videos, source images, labels, drafts or exported screenshot collections. This guide contains no real recording screenshots. Source media is never deleted by recoverable Trash.

01 / LOAD AND FIND A MOMENT

Start with the complete source

Extract a new local recording

python3 scripts/extract_new_recording.py

Enter the source video path, an existing destination parent folder and a recording name. The extractor creates a dated folder, copies the video and saves every extracted frame, timestamps and a manifest beside it. Keep both paths outside the repository.

Start the dashboard with --archive pointing to that dated folder. Media extraction and human approval are separate steps.

Use the first tab as your gallery

  1. Choose the recording and review window in Frame review.
  2. Scan the overview, then choose Every source frame to inspect changes between overview samples.
  3. Use filters and pagination to find candidates. A suggestion is not an approval.
  4. Click a thumbnail to open that exact source frame in Frame editor.

02 / INSPECT AND DECIDE

Inspect the exact state

In Frame editor, compare text, control availability, counters, rewards and intermediate animation states. Inspect small regions before treating similar images as duplicates.

ControlPurpose
Previous / Next frameInspect neighboring source timestamps.
Time jumps / timelineMove to a nearby real source frame. Navigation does not save decisions.
K / A / R / UKeep / Animation / Same state / Unsure. Decisions save to the local dataset.
Arrow keys / SpaceSingle-frame movement / playback where a source preview is available.
1 / MStage an exact frame / save the staged group. See the next page.

Shortcuts ignore text fields, held-key repeats and busy saves. Frame staging requires the source image to finish loading and playback to be paused. Decision/transport shortcuts work in the editor, not unrelated tabs.

Recover from a stale or uncertain save

If another window writes, reload decisions before trying again. A lost response may mean a write succeeded: inspect the saved state instead of repeatedly clicking Save. The tool does not automatically retry mutations.

No general Undo/Redo. Clear yellow staging cancels an unsaved draft. Move a member back to reverse a transfer; Ungroup removes group metadata without deleting frames. Restore from Trash reverses dashboard hiding. Do not restore an old whole-dataset checkpoint to undo one recent action.

03 / ORGANIZE EXACT FRAMES

Group sequences, not guesses

1Stage exact frame in yellow
RepeatChoose at least two members
MSave one green unit

Staging is separate from Keep. Only the exact marked members join the group: no neighboring or intervening frames are inferred. Use Expand members to inspect them.

Merge, number and color

Choose New group (yellow staging) beside a gallery frame to stage that exact card. Choose an existing Group N and Merge to append it. Merge does not remove another membership; use Move for a transfer.

In Groups, choose a unique positive group number and a color, then press Save group settings. Editing fields alone does not save. Stable internal identities survive renumbering.

Correct membership

For each member, choose a destination and Move, or use Remove from group. If fewer than two members would remain, confirm dissolving the source group; remaining frames become individual. Keep/Trash and direct frame categories are preserved.

Saga map is a category, not a group

Check or uncheck Saga map, then press Save category on the exact frame or group. A category on a group does not tag its members or approve them. Custom labels such as Pop-up are not included in version 2.

Different meanings: Group = these exact frames form one unit. Category = a label on that reference. Keep = a saved individual decision. Yellow = an unsaved staging draft.

04 / CLEAN UP WITHOUT DELETING MEDIA

Use recoverable Trash

Discard one frame directly inside a group

Use Move to Trash on a member in Groups or an expanded gallery unit. It hides the exact frame without removing membership or changing categories. Groups still shows the reference and offers Restore from Trash. Normal gallery expansions omit trashed members.

Hide non-selections across the recording

  1. Save or clear yellow staging and finish manual drafts.
  2. In Frame review, press Move unselected frames to Trash.
  3. Review the recording name, total source frames, selected count, existing Trash and exact eligible count.
  4. Confirm only when the whole-recording scope is intended. Cancel or Escape writes nothing.
Protected from new cleanupNot an approval by itself
Non-trashed individual Keep points and selected-unit members, deduplicated.Metadata-only groups, intervals, categories and unsaved staging.

Existing Trash stays in Trash. Cleanup preserves cases, histories, groups and original media. It does not generate diagrams, export a collection, fit a model or contact Jira.

Restore, don't re-extract. Use the Trash view for individual restoration. Historical retained-only archives cannot restore previously physically removed files and remain read-only for visibility changes.

05 / REVIEW SIMILARITY AND EXPORT

Keep evidence, not just endpoints

Find similar frames

In LLM learning, choose the recording and refresh its selection summary. Find similar frames compares all unordered pairs across up to 1,000 individual retained Keep frames and displays up to 40 closest candidates. It never silently truncates to the first 300.

Inspect full-resolution text, controls and counters. Tick Discard only for exact frames you explicitly reviewed. Keep all / clear proposed discards clears the current scan's local discard choices; it does not select unreviewed source frames or save new Keep labels. A no-op message means nothing was marked.

Save a selection package

Review closeout options and exact counts before confirming. Similar-frame discards require recoverable cleanup. Retained originals are copied and hash-verified; optional diagrams and descriptive comparisons are separate options. A closeout is not model training.

Use chronological diagrams carefully

Saved collections and HTML/JSON/Mermaid diagrams appear in Diagrams and collections. An arrow means only "later in this recording": not a tap, purchase, branch or causal link. Saved packages retain their export revision rather than silently following current decisions.

For a local Figma import, use self-contained SVG diagrams with embedded previews and exact frame/time labels. Importing that file into a cloud document may upload its images; review destination and sharing first. A local export is not proof of a successful Figma import.

Learning boundary. Keep selected intermediate states. Separate observations, interpretations and unknowns. Omitted frames are not negative labels. No automatic LLM call or weight update occurs.
